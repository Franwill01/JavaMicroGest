## Séquence d'un retrait

```mermaid
sequenceDiagram
    actor Agent
    participant Vue as Contrôleur JavaFX
    participant Service as MicroGestService
    participant Base as Hibernate / H2
    Agent->>Vue: Choisir adhérent et montant
    Vue->>Service: saveOperation(RETRAIT)
    Service->>Base: Début transaction
    Service->>Base: Vérifier utilisateur et rôle
    Service->>Base: Verrouiller l'adhérent
    Service->>Base: Calculer dépôts moins retraits validés
    alt Solde suffisant et adhérent actif
        Service->>Base: Insérer opération, audit et email
        Service->>Base: Commit
        Service-->>Vue: Opération validée
        Vue-->>Agent: Fermer formulaire et actualiser
    else Solde insuffisant ou saisie invalide
        Service->>Base: Rollback
        Service-->>Vue: Erreur métier
        Vue-->>Agent: Message, formulaire conservé
    end
```

## Cycle d'un prêt

```mermaid
stateDiagram-v2
    [*] --> EN_ATTENTE: Demande par agent ou administrateur
    EN_ATTENTE --> EN_ATTENTE: Modification
    EN_ATTENTE --> VALIDEE: Validation par responsable
    EN_ATTENTE --> ANNULEE: Annulation par responsable
    EN_ATTENTE --> [*]: Suppression de la demande
    VALIDEE --> VALIDEE: Remboursement partiel ou total
    VALIDEE --> ANNULEE: Sans remboursement validé lié
```

Le statut VALIDEE est conservé après remboursement intégral. Le restant dû nul indique que le prêt est soldé ; aucun nouveau remboursement positif n'est alors accepté.
